# Elite Pro: from idea to screen

One-page site for Elite Pro, a 360° creative agency in Riyadh. Arabic and English, built as a single `index.html` with three.js (from a CDN) and local media in `media/`.

Run it locally (it needs a web server; opening the file directly will not load the 3D):

```bash
python3 -m http.server 5191 --bind 127.0.0.1
```

Then open http://127.0.0.1:5191
